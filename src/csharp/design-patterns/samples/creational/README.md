# Creational Pattern Samples

This executable is the presentation edge for creational examples. It references `../../creational/DesignPatterns.Creational.csproj`; the pattern contracts and collaborators remain in that library.

Run it with:

```powershell
dotnet run --project src/csharp/design-patterns/samples/creational --configuration Release
```

The source comments identify what each demonstration shows, where the pattern boundary lives, and why the interaction matters.
