# Interpreter

## Intent

Define a representation for a language grammar and interpret sentences in that language.

## Use when

The grammar is small, stable, and expression evaluation needs to be explicit and extensible.

## Avoid when

The grammar is large, fast-changing, or better served by a parser generator.
